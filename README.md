# 贪吃蛇 (Snake)

用 Python 标准库 **tkinter** 写的贪吃蛇小游戏。

**不需要安装任何第三方库**（没有 pygame，没有 numpy），下载下来直接就能跑。

---

## 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.x（开发环境为 **3.14.6**） |
| tkinter | Python 官方安装包**默认自带**，一般不用单独装 |
| 第三方库 | **无** |

> **怎么确认 tkinter 装没装？**
> 命令行里执行 `python -c "import tkinter; print(tkinter.TkVersion)"`，
> 能打印出版本号（如 `8.6`）就说明没问题。
>
> 如果报 `ModuleNotFoundError: No module named 'tkinter'`，说明当初装 Python 时
> 没有勾选 `tcl/tk and IDLE` 组件，需要重装 Python 并勾上它。

## 玩法

- 吃到红色的食物 **+1 分**，同时蛇身变长一节
- **每吃一个，移动速度加快一点**（最快到某个上限就不再加快）
- 撞到墙壁 → 结束
- 撞到自己身体 → 结束
- 蛇填满整个棋盘 → 通关

游戏结束时画面中央会显示结束原因，按 `R` 或空格即可重开一局。

## 代码特点

- **单文件**，`snake.py` 一共 227 行，从头到尾能一口气读完
- **零依赖**，只用 `random` 和 `tkinter` 两个标准库
- **画面不闪**：背景和网格只在启动时画一次，每帧只重绘"会动的部分"（蛇和食物）
- **按键不丢**：方向键有 2 格的输入缓冲队列，快速连按（比如"上"接"左"再拐弯）不会漏掉，也不会出现 180° 掉头撞死自己
- **重开干净**：用"代号"机制作废旧定时器，游戏中途按 `R` 重开不会出现两条蛇同时在跑

### 想改手感？

打开 `snake.py`，最上面有一段可调参数：

```python
CELL = 22          # 每个格子的边长（像素）
COLS = 22          # 横向格子数
ROWS = 22          # 纵向格子数
START_SPEED = 160  # 每走一步间隔多少毫秒，数字越小蛇越快
MIN_SPEED = 65     # 速度上限
SPEED_STEP = 5     # 每吃一个食物加快多少毫秒
```

把 `START_SPEED` 调小（比如 `80`）就是困难模式。
